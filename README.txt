KORA V16 — Character Confirmation Fix

Based on the exact V15 project supplied for testing.
Fixes:
- “THIS IS MY CHARACTER” no longer depends on native disabled state.
- The selected character index is stored on the confirmation button.
- Confirm button click uses both the current selection and button fallback.
- Character selection remains gated behind registration.
- Selecting a character saves the choice and opens its chat.

All previous V15 files/features are preserved.
